EHR Data Entry & Workflow Case Study
Independent Portfolio Project Walkthrough
1. Project Objective
This project documents the development of a sandbox clinical database inside an open-source Electronic
Health Record (EHR) environment (OpenEMR). The simulation validates hands-on competency in high-volume
patient demographic data entry, insurance verification routing, clinical encounter mapping, and regulatory
compliance standards without direct workplace access.
2. Data Protocol & Validation Standards
To mirror professional healthcare administration standards, the following rigorous administrative guidelines
were established during the execution of this project:
• Patient Demographics & Identification: Prioritized complete entry of core fields (Legal Names, Dates of
Birth, Gender, Active Status) to emphasize medical record accuracy and mitigate risk of patient matching
errors.
• Payer Substitution & Optimization: Actively managed software inventory limitations by dynamically
mapping invalid commercial options to valid regional payers (e.g., substituting unavailable carriers for active
providers), proving systems adaptability.
• Revenue Cycle Routing & Care Types: Structured independent coordination workflows for complex
auto/PIP accidents by logging custom clear text directives in the system Billing Notes, ensuring proper data
tracking before bill generation.
• Information Security & Privacy: Exercised HIPAA-aligned principles including data validation rules,
alphanumeric formatting accuracy for Medicare Beneficiary Identifiers (MBIs), and clear screen clearing
protocols.
